# Совет

Приложение для iPhone: несколько ИИ отвечают на вопрос, обсуждают ответы друг друга, пишут итог и голосуют за него.

Сервер не нужен. Телефон обращается к ИИ-сервисам напрямую. Ключи хранятся только на телефоне и в этот репозиторий не попадают.

## Как опубликовать

1. Создайте публичный репозиторий на GitHub и загрузите в него все файлы, сохранив папки `icons` и `vendor`.
2. Откройте Settings, затем Pages. В разделе Source выберите Deploy from a branch, ветку `main` и папку `/ (root)`, затем нажмите Save.
3. Через пару минут приложение откроется по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

## Как установить на iPhone

1. Откройте адрес в Safari.
2. Нажмите «Поделиться», затем «На экран “Домой”».
3. Откройте приложение с экрана «Домой», зайдите в настройки, добавьте ключи и нажмите «Проверить участников».

Вводите ключи именно в установленном приложении: ключи, введённые в Safari, туда не переходят.

## Чужие библиотеки

В папке `vendor`: pdf.js (Apache-2.0) для чтения PDF и JSZip (MIT) для чтения .xlsx и .docx. Они работают на телефоне и никуда не обращаются.
